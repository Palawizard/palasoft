## What it does

Layout Manager 2 saves work layouts and puts them back in place whenever you want. A layout is a list of actions, in order:

- open an app;
- move a window that’s already open;
- open a browser window (Edge, Chrome or Firefox).

Each window can take the whole screen, a half, a quarter, the center, or an area you choose, on the screen you want. If a matching window is already open, it reuses it instead of opening another one. You can also minimize the windows that aren’t part of the layout.

The interface is in French, follows the Windows light or dark theme, works offline, needs no account, and updates itself.

## Install

1. Download the file with the Download button, then open it.
2. It installs for your Windows account.

## Good to know

- This is a beta.
- It can’t move an app that runs as administrator.
- No keyboard shortcut to launch a layout yet.
