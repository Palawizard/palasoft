## What it does

palaswitch switches the profile of your Logitech gaming mouse without opening G HUB: one click in its menu or a keyboard shortcut is enough.

- It stays next to the clock, in the notification area. Its icon shows the number of the active profile, or a crossed-out mouse when no mouse answers.
- Click the icon to open the menu: your profiles, with a tick on the active one. Pick one to make it active.
- In the settings, you give each profile a name, shown in the menu instead of “Profile 1”, and a keyboard shortcut, for example Ctrl+Alt+F1. Shortcuts also work in full-screen games.
- “Start with Windows” starts it on its own when you sign in, straight next to the clock.
- It only picks the active profile: buttons, DPI, lighting and macros are still set in G HUB or Onboard Memory Manager.

## Install

1. Download the file with the Download button, then open it.
2. It installs for your Windows account, without administrator rights, then palaswitch starts. A notification tells you where its icon is.
3. If Windows puts the icon behind the ^ arrow of the taskbar, drag it onto the taskbar to keep it in sight.

## Good to know

- Close G HUB and Onboard Memory Manager while palaswitch runs: they talk to the mouse on the same channel.
- A wireless mouse that hasn’t moved for a few minutes goes to sleep and stops answering: move it, then try again.
- Tested with a G502 X PLUS, with the cable and with the wireless receiver. Other Logitech mice that keep their profiles in their own memory should work, but none has been tried yet.
- Shortcuts don’t work in a game run as administrator.
- It updates itself: once a day, it checks for a new version and offers it in its menu. That’s the only time it goes online.
- The interface follows the language of Windows: French or English.
- To uninstall it: Settings, Apps, Installed apps. Your settings stay in `%APPDATA%\palaswitch`; delete that folder to remove them too.
